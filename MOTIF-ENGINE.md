# Motif Engine
Great anthems = **one idea, developed obsessively** (cf. Darude "Sandstorm", Robert Miles "Children").

## Core Generation
1. **Interval pool** by intent (euphoric: P4/P5/M6/m7/oct · dark-psy: m2/m3/tritone/P5 · progressive: M2/M3/P4/P5).
2. **Contour**: ARCH / ASCENT / DESCENT / WAVE / PLATEAU.
3. **Rhythmic cell**: driving / flowing / syncopated / sparse.
4. Start on a stable degree (1/3/5), ensure ≥1 stepwise motion, end implying continuation.

## Scoring (0-100)
Singability (stepwise ratio · 30) + contour clarity (25) + interval variety (25) + length sweet-spot (20).

## Transformations
TRANSPOSE · SEQUENCE · INVERT · RETROGRADE · AUGMENT · DIMINISH · TRUNCATE · EXTEND · RHYTHMIC_SHIFT · ORNAMENT.

## Tension → Transform selection
- Rising tension → DIMINISH / SEQUENCE (urgency)
- Peak → TRANSPOSE(0) (maximum recognition)
- Falling → AUGMENT / RETROGRADE (space)
